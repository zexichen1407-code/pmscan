2. **去重逻辑：站得住（强），caveat 偏保守。**
   - agent dedup key=(txHash,asset,type,timestamp,outcomeIndex,side,usdcSize)。我用此 key 重算：**301,223 行 = 301,223 个 distinct（残留重复=0）**。
   - 更强 key（再加 conditionId+price+size）下仍是 **301,223 个 distinct（over-merge=0）**。即**没有任何两行仅在强 key 字段上不同**——SUMMARY caveat 担心的"少量合法同字段行被过度折叠"经检验**为零**，该 caveat 偏保守，实际无此风险。既不漏删（无残留重复→不会多算）也不误删（无过度折叠→不会少算）。
