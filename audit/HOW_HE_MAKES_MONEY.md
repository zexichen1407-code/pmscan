# 钱包 0xp3nny (链上名 e46m3) 如何赚钱 — 全数据审计报告

> 钱包自报 bio = **"arb"**。全生命周期 2026-04-10 → 2026-06-25,**301,223 条活动记录**,**$8.41M** TRADE 成交量,**2,901 个事件**。
> 结论一句话:这是一台 **高频、薄利、规模化** 的 Polymarket 套利机器人,核心引擎是 **neg-risk NO 转换 (CONVERSION)**,辅以 **同市场 YES+NO 合并 (MERGE)** 和 **完整集合荷兰赌 (REDEEM)**。所有锁定利润均由 **活动数据的套利恒等式** 独立推导,**不依赖 Polymarket 自报 PnL**(这是本报告的可信度来源)。

## 1. 赚钱模型 (The Money-Making Model)

他不做方向性投机,而是利用 Polymarket 三类 CTF / NegRiskAdapter 机制,把一篮子互补头寸"折叠"成保证现金。三个子策略:

### 策略 A — Neg-Risk NO 转换 (主引擎,绝对统治地位)

**机制**:在一个 N 选项的 neg-risk 事件里(NBA 冠军 14 队、BTC 价格 11 桶、选举 2 人),给**每个选项都买 NO**,使各 NO 价格之和略低于 (N−1)。然后用 NegRiskAdapter 的 **CONVERSION**:一套完整的 N 个 NO 代币 → 保证返还 **(N−1) USDC**(因为只有一个选项会赢,即只有一个 NO 归零,其余 N−1 个 NO 各值 \$1)。
**每套边际** = (N−1) − Σ(NO_i 的 vwap)。

| 维度 | 数值 |
|---|---|
| 事件数 | **2,058 / 2,901** (71%) — 占绝对多数 |
| CONVERSION 操作 | 51,406 次 / 释放名义 \$1,916,299 |
| 干净完整集合**已测**锁定 | **\$4,291**(890 个干净事件,每套中位数仅 **0.0076 USDC**) |
| 额外**推断上界** | \$86,077(503 个 partial / k-of-N 不等量事件,**非已证明**) |
| 出现品类 | 体育(NBA 冠军)、加密(BTC 价格桶)、政治(选举)、公司 |

> 特征:**单套利润是亚分级别的**(中位 0.76 美分/套),靠**海量重复 + maker 折扣**赚钱,典型做市商收割,而非肥差错价。

### 策略 B — 同市场 YES + NO 合并 (MERGE)

**机制**:在**同一个 conditionId** 上同时买 YES (价 p) 和 NO (价 q),只要 p+q<1,就把配对的 1 YES + 1 NO **MERGE** 成 \$1。
**锁定** = (1 − p − q) × merge_size。**零结算风险**,完全活动数据可测。

| 维度 | 数值 |
|---|---|
| 事件数 | **400 / 2,901** |
| MERGE 操作 | 46,104 次 / 毛 \$1-配对赔付 \$1,203,222 |
| **已测**锁定(merge 主导子集) | **\$7,706** |
| **已测**锁定(所有双腿 merge 事件) | **\$12,133** |
| 出现品类 | 体育(网球、足球世界杯赛事)为主 |

### 策略 C — 完整集合荷兰赌 / 持有至赎回 (REDEEM)

**机制**:跨子市场买一篮子接近完整的看好组合,结算时恰好一个赔 \$1,通过 **REDEEM** 兑现。

| 维度 | 数值 |
|---|---|
| 事件数 | 154 (荷兰赌) + 110 (持有至赎回) |
| REDEEM | 1,273 次 / 毛 \$238,815(其中 dutch \$98,762 + hold \$10,915) |
| 净利润 | **每事件仅几百到 ~\$3,600**,毛 REDEEM **大部分是本金返还**,净利推断、噪声大 |
| 出现品类 | 体育(足球世界杯多盘口事件) |

### 辅助收入
rebates + rewards + referral + yield 合计 **\$6,476**(maker 返佣 / 流动性奖励)。

**汇总(可清晰证明的活动锁定):** 干净转换 \$4,291 + 合并 \$12,133 + 小额荷兰赌净利 + 返佣 \$6,476 ≈ **数万美元量级的已证明锁定**;那个抢眼的 \$86K 是 partial 转换的**推断上界,非已证明**(见第 3 节)。

## 3. 诚实的限定 (Honesty / Caveats)

1. **锁定利润 = 活动数据套利恒等式推导,独立于 Polymarket 自报 PnL** —— 这是优势,不是弱点。
   - MERGE:locked = (1 − p − q) × merge_size(零结算风险,完全可测)。
   - CONVERSION:locked = ((N−1) − Σ vwap_NO) × **匹配套数**(按最小腿封顶,不是按转换 size)。
   - REDEEM:毛额 ≠ 利润,**大部分是本金返还**,净利需减去篮子买入成本,推断且噪声大。

2. **gas / CTF 费 / maker 返佣均未在活动数据中,双向排除**。会少量(几个 bp)影响净实现 PnL。

3. **转换数学是有界、非精确的地方已明确标注**:
   - CONVERSION 行只携带 neg-risk 伞 conditionId + 单一 size,**不记录每腿篮子组成**(哪 k 个选项、各多少)。因此对 partial / 不等量篮子,真值只能给区间。
   - 例 5 (NBA):真值 ∈ **[\$1,809, \$31,533]**,头条用保守**下界**。
   - 第 8 类的 **\$86,077 是推断上界,非已证明锁定**,不计入"可清晰证明"汇总。

4. **方向性余货已排除**:未合并的 NO 超额腿、单-NO partial 转换(返还 0 现金 + 互补 YES)带方向性风险,不计入锁定利润。

5. **窗口裁剪**:部分篮子跨数据窗口边界(尤其荷兰赌),整集净现金流可能呈负(如 NBA 净实现 −\$164,991),因为转换 "size" 是抵押信用而非纯现金,且头寸在窗口外结算 —— 这不是亏损,是仓位未平 + 残值待赎回。

6. **量级定性**:可清晰证明的活动锁定为**数万美元量级**,单套利润亚分级,靠 \$8.41M 成交量的**极高周转 + 返佣**放大。这是一台薄利做市套利机器,不是单笔肥差。
