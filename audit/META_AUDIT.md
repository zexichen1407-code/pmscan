## 【双方共同盲点】两份报告都没覆盖、却很关键

### 盲点 1（最严重）：usdcSize 不等于 PnL，活动数据跟利润完全对不上账
我用活动数据做现金流 PnL 重建（`meta_blindspots.py`）：
- BUY −$8.34M、SPLIT −$0.125M（流出）；SELL +$0.074M、MERGE +$1.20M、REDEEM +$0.24M、rewards +$0.006M、当前持仓 +$0.006M（流入）；CONVERSION $1.92M（方向不明）。
- 无论 CONVERSION 算流入还是流出，重建结果都是 **−$5.0M 到 −$8.9M**，**与 lb-api 的 +$278,513 利润差了一个数量级、连符号都不同。**

**含义**：活动文件里的 usdcSize 在结构性行（MERGE/CONVERSION/REDEEM/SPLIT）上是**名义量（notional）不是现金 PnL**（样本行 `price=0, side=空, outcomeIndex=999` 印证）。**+$278K 利润完全产生于 Polymarket 内部的盯市引擎，无法从活动数据推导，也无法用活动数据交叉验证。** 两个 agent 都隐含地把 301,223 条活动当作利润的佐证，但活动数据对 PnL 实际上**完全沉默**。这是整条结论里最软、却被双方当作硬证据的一环。

### 盲点 2：gas 成本全程缺失
活动记录里**没有任何 gas/fee/cost 字段**（21 个字段全列出，无一相关）。301,223 笔链上操作（约 97k 结构操作 + 202k trade）在 Polygon 上的 gas，**没有计入 +$278K**。对一个靠 <$1 篮子价差套利的策略，gas 是真实经营成本。虽然 Polygon gas 便宜、且代理模式下可能由中继补贴（nonce=1 暗示代理自身不付 gas），但"利润是否已净掉交易成本"这个问题，两份报告都没问。**+$278K 是毛盯市利润，不是净到手。**

### 盲点 3："近期转亏"是未实现盯市，不是已实现亏损
lb profit 7d=−$17,171 / 30d=+$86,209 / all=+$278,514 全是**盯市（mark-to-market）**。我查活动近况（`meta_recency.py`）：钱包在 7d 窗口内仍 TRADE 20,674 笔、BUY $1.54M，**仍在高强度运行**；近 4 天（6/22–6/25）日活从 5–10k 降到 2k 左右、略有放缓但未停。
**含义**："7d 亏 $17K"是一个**仍在活跃持仓的钱包的盯市浮动**，无法与已实现亏损区分。把它表述为"近期转亏"会误导——它可能只是未平仓头寸的标记波动，下一次结算可能翻正。审计 agent 在自洽性里说"7d 回撤落在 30d 盈利内、逻辑通顺"——逻辑通，但**没点破这是浮盈浮亏、不是落袋亏损**。

### 盲点 4：窗口级 volume 对账失败，被误归为"正常漂移"
审计 agent 的对账只在 `all` 聚合上成立（struct sum 距 lb 0.57%）。我把活动按时间戳切片做窗口级对账（`meta_recompute.py` 末段）：
- 1d：活动 struct $273k vs lb-api $44k（差 6 倍）
- 7d：活动 struct $2.20M vs lb-api $935k
- 30d：活动 struct $8.03M vs lb-api $6.97M（最接近，但 TRADE-only 反而更低）

**含义**：lb-api 的**窗口** volume 用的是和 `all` 不同的口径（可能窗口内排除结构性 mint/merge，或用不同的时间归属），**根本没人逆向出来**。审计 agent 把 1d/7d volume 比快照高 +$10.2k 解释为"正常时间漂移"——但更根本的问题是窗口口径本身无法用活动数据复现，"对账口径正确"这个 ✅ 只对 `all` 成立，不对窗口成立。

### 盲点 5（轻微）：SPLIT 22 笔 vs MERGE 46k 笔的"套利指纹"辩护是合理推断但非证据
审计 agent 说"SPLIT 少 MERGE 多 = 靠买腿凑互补集再 MERGE 套利的指纹，不可疑"。这个机制解释**合理且与 neg-risk 授权（链上已证）方向一致**，但它仍是审计 agent 的推断，不是数据直接证明的——CONVERSION/MERGE 行的 `side` 全空、`price=0`，数据本身不标方向。属"可辩护的推断"，不是"已测量"。审计 agent 没有把它越界标成 measured，分寸尚可，但报告语气("不可疑")略强于证据。
