## Phase 1 关键发现(实盘观察, 真实订单流)
**边际与成交率是反比的**(两端都用真实数据验证过):
- 热门紧盘: 成交多(53笔/100s) 但 0 命中——要接到单得让掉 >3分边际(倒贴)。
- 冷门宽盘: 边际肥(5–30分) 但几乎没成交(3笔/110s)。
- 甜区(边际+成交都不差)正是 bot 抢光的地方; 0xp3nny 靠速度/规模/返佣在那做, 且已浮亏。
- 选盘已改为按"边际×成交量"挑甜区(`observe.pick_markets`)。
- ⚠️ 这是**廉价验证的核心产出**: 在投钱投基建前, 用真盘口判断"这点边际在你身上活不活得了"。需后台长跑(分钟级快照不够)。
